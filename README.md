# Desafio CloudFormation AWS

## 📌 Sobre o projeto

Projeto desenvolvido para demonstrar a utilização do AWS
CloudFormation na criação automatizada de infraestrutura.

## 🎯 Objetivos

- Aprender Infrastructure as Code
- Criar recursos AWS utilizando CloudFormation
- Trabalhar com arquivos YAML
- Documentar uma infraestrutura
- Utilizar Git e GitHub

## 🏗️ Arquitetura

CloudFormation
      │
      ▼
   S3 Bucket

## 🛠️ Tecnologias

- AWS CloudFormation
- Amazon S3
- AWS CLI
- YAML
- Git
- GitHub

## 🚀 Como executar

1. Clone o repositório
2. Configure a AWS CLI
3. Acesse a pasta do projeto
4. Execute o template CloudFormation
